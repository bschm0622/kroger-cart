# Kroger Cart: Agent Guide

**Setting this up for someone for the first time? Follow [SETUP.md](SETUP.md).**

This repository is Kroger Cart: a local web page for building a Kroger order, on top of the `kroger-pp-cli` command-line tool originally generated by [CLI Printing Press](https://github.com/mvanhorn/cli-printing-press).

## Local Operating Contract

Start by asking the generated CLI for current runtime truth:

```bash
kroger-pp-cli doctor --json
kroger-pp-cli agent-context --pretty
```

Use runtime discovery instead of relying on a copied command list:

```bash
kroger-pp-cli which "<capability>" --json
kroger-pp-cli <command> --help
```

Add `--agent` to command invocations for JSON, compact output, non-interactive defaults, no color, and confirmation-safe scripting:

```bash
kroger-pp-cli <command> --agent
```

Before running an unfamiliar command that may mutate remote state, inspect its help and prefer a dry run:

```bash
kroger-pp-cli <command> --help
kroger-pp-cli <command> --dry-run --agent
```

Use `--yes --no-input` only after the target, arguments, and side effects are clear.

For install, auth, examples, and longer product guidance, read `README.md` and `SKILL.md`. This file intentionally stays small so repo-local agents get invariant local guidance without duplicating the generated docs.

## This repository

The CLI, MCP server and skill were first generated by CLI Printing Press; since then this repo is maintained by hand. Edit it directly, and don't regenerate over it: a fresh print would replace the web UI, the scripts and every fix made since. `.printing-press.json` records the original run for provenance only.

Notable changes go in `CHANGELOG.md` under **Unreleased**.
