Sign in to Kroger

Sign in on kroger.com in Chrome, then import that session here. macOS asks once to use your keychain; choose Always Allow.

Not using Chrome? Paste the session by hand
  1. On kroger.com, signed in, open DevTools (⌥⌘I) → Network → filter atlas.
  2. Click a customer-profile/v1/profile request whose Status reads 200. A cookie from any other request signs you in but every call fails.
  3. Headers → Request Headers → right-click Cookie: → Copy value, and paste below.

Tell Kroger Cart which store you shop at

Search and stock depend on it. This takes one copy and paste:

  1. On kroger.com in Chrome, search for anything.
  2. Open DevTools (⌥⌘I) → Network, type products-search in the filter box.
  3. Right-click that request → Copy → Copy as cURL.
  4. In Terminal, from the Kroger Cart folder: pbpaste | ./kroger-pp-cli auth set-store -
  5. Reload this page.
